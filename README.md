Ce projet illustre une architecture client-serveur simple en Java, où le client envoie des opérations arithmétiques au serveur, qui les traite et renvoie le résultat. 
Le serveur écoute sur le port 1234 et accepte des expressions comme 5 * 3. Il prend en charge les opérations de base (+, -, *, /), gère les erreurs comme la division par zéro ou les opérateurs invalides,
et répond avec le résultat ou un message d’erreur approprié.
