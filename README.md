Ce projet présente une application client-serveur en Java basée sur les sockets et la sérialisation d’objets. Le client envoie des opérations mathématiques sous forme d’objets sérialisés au serveur, qui les traite et renvoie le résultat. Il prend en charge les opérations arithmétiques de base (+, -, *, /), gère les erreurs comme la division par zéro ou les opérateurs invalides, et utilise les flux d’objets pour la communication.
